# 全身を描ける落書き画面（4.1）

頭・胴体・手足の別々の枠をなくし、全身を1枚の紙に描く方式へ変更しました。描いた位置関係を保ったまま厚みを付け、横に完成形を表示します。

## 描き方

1. 白紙、ひと、犬、ドラゴンから下絵を選びます。切り替えは「戻す」で取り消せます。
2. 「ペン」で線を描きます。始点へ勝手につながりません。塗りつぶした形が必要なときは「面」を使います。
3. 「塗りつぶし」で、ペンで囲んだ内側をタップします。複数の線で囲んだ範囲にも対応し、輪郭の線を残したまま面を追加します。内側の輪郭は穴として残ります。すでにある面をタップすると色を変更できます。紙の端までつながる開いた範囲は塗らず、画面に理由を表示します。
4. 18色のパレット、またはカスタム色で好きな色を選びます。線の太さと立体の厚みも変更できます。
5. 「選択・移動」で線や面をつかみ、配置・拡縮・回転・左右反転・複製・削除ができます。選択中の色や厚みも変更できます。
6. 足・翼・しっぽの動きを付けたい線や面にタグを指定します。本数は固定されていません。最初に描いた点を軸に動くので、付け根から描くと調整しやすくなります。
7. 正面・斜め・横のプレビューを確認して「誕生させる」で保存します。

消しゴムは線を部分的に消し、面はひとまとまりで消します。操作は戻す・進むに対応。編集中に画面を閉じても、同じキャラクターを開き直すと下書きが残ります。ただし再読み込みを越えて残すには「誕生させる」が必要です。

## 形状と互換性

- 立体は絵を押し出す方式です。線や面の前後関係と厚みを持ちますが、奥行き方向も自由に造形するモデリングツールではありません。
- 人間型への自動補完は行いません。白紙は白紙のままで、描くまで誕生できません。
- 描いた線と面は合計96個、保存・立体化時は各128点まで整理します。上限に達したときは通知し、部分消去で上限を越える場合も他の線を勝手に削除しません。
- 旧形式のキャラクターはそのまま遊べます。編集時だけ1枚の紙へ変換し、誕生させるまで元の保存を変更しません。
- 新形式では描いた量・外形・厚みから能力を計算します。色の選択による能力差はありません。能力計算変更に伴い、4.0以前のタイムは旧記録へ退避します。
- 保存形式は4。キャラクター、EXP、解放進行を引き継ぎます。

縦画面はプレビューと紙を上部、設定を下部へ配置。横画面は紙と設定を並べます。設定が収まらない場合はスクロールできます。実機のペン・指での描き心地は未検証です。

バケツは256×256の境界判定から編集可能な輪郭へ変換します。極細・微小な隙間や非常に複雑な輪郭は画面のピクセルと完全に一致しない場合があります。保存する輪郭は穴も含めて128点まで。複雑すぎる範囲は通知し、既存の線を削除しません。

# ステージ1：こもれびの大樹の里（4.1）

浮島を順番に渡るコースから、80×100の地続きの谷を自由に探索するステージへ変更。中央の草原、西の果樹園、東の丘上遺跡、北の大樹の闘技場を歩いて行き来できる。ステージ2〜5も5.0で[ミッションフィールド](EXPEDITION_STAGES.md)へ変更した。

## 遊びの流れ

1. 好きな順にミッションへ向かう。ミッション欄で選択すると地図で強調し、目的地への方向と距離を表示する。
2. 条件を満たすと、その場所に紋章が出現する。触れて回収するとHPが回復する。
3. 3つの紋章を回収すると北の門の結界・衝突が解除される。開いた門の奥へ進むとクリア。

| 場所 | ミッション | 操作と判断 |
|---|---|---|
| 西・果樹園 | エリアの敵3体を倒す | 接近してACTION。敵が赤く膨らんだら離れるかジャンプ |
| 東・古代遺跡 | 石碑3つを起動する | 坂を登って石碑の近くでACTION。石積みの上には寄り道のかけら |
| 北・大樹の闘技場 | 大樹の番人を倒す | 赤い円の衝撃波を範囲外・ジャンプで回避。緑色になって休む間に接近してACTION |

ボスはHP150。通常時は防御し、攻撃予兆→衝撃波→回復待ちを繰り返す。体型による移動速度・ジャンプ・攻撃力・防御力を引き継ぐ。

紋章、石碑、倒した敵、倒したボスは同じ挑戦中の死亡・リトライで復活しない。未討伐ボスのHPはリトライで全快。紋章を1つ取ると再出発位置が中央広場へ移る。ページを閉じた場合の途中復元は行わない。

## 谷の地形と寄り道（4.1）

- 2m間隔の三角形地形で、描画・物理衝突・高さ判定を共通化。果樹園とボスの戦闘域は平坦、遺跡と西の丘は広い坂でつなぐ。
- 中央を小川が横切る。木の橋で渡るか、浅い川底へ降りて移動できる。水中では移動が遅くなり、橋の上には影響しない。
- 西の丘に登れる展望台、果樹園脇に入れる洞窟、遺跡脇にジャンプで登る石積み。それぞれ探索用のかけらを配置。発見すると場所名を表示し、地図の印を更新する。
- 大樹は幹・枝・根と複数の樹冠で構成。門を隠さない位置へ移動。果樹園の実や柵、壊れた遺跡の柱で地域ごとの輪郭を変える。
- 短い横画面ではカメラを近づける。草・石・樹木はまとめて描画し、中・高画質では太陽の影、低画質では簡易影を使用する。

## 案内と見た目

- 山と木に囲まれた連続地形、分岐する道、段丘とアーチ、大樹の闘技場。
- 北を上にしたミニマップ。白点が自分、番号がミッション、門の色が封印状態を示す。
- 縦画面はミッション欄を初期状態で折りたたむ。選択先の方向と距離は閉じても残る。
- 敵の予兆色、ボスの攻撃範囲・残りHP・弱点時間、攻撃の輪、光る紋章。
- 門に先に着いても「あと何個必要か」を表示。ACTIONだけでは門を開けない。

## 批評で修正した点

独立エージェントにコードと実画面を提示し、門の通行状態、地図が閉じた場合の案内、段差のジャンプ説明を指摘された。物理的な門、常時表示の方向・距離、遺跡接近時の操作案内で対応した。小画面のHUDとレベル表示の重複を解消し、カメラもキャラクターへ近づけた。

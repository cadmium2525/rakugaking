# ステージ批評と改善記録

## 5.0 — 各ステージの制作・批評ゲート（2026-10-04）

実装 → 物理テスト → 実入力のブラウザ完走・PC/縦/横撮影 → 独立批評 → 指摘修正 → 再評価の順に進める。前ステージの合格が出るまで次ステージは実装しない。合格は今回の改善範囲についての評価であり、商用品質やスマートフォン実機性能の保証ではない。

### ステージ2：風車の谷と雲海の灯台 — 合格

初回指摘：開始の木がキャラクターを隠す。風車の裾・家・アーチ柱・門柱の衝突が不足。風車復旧後も強風の表示が残る。休憩所が橋の下に埋まっている。

修正：開始周辺の木を除去。主要建造物へ地形高に合わせた衝突を追加。復旧後は緑の凪表示へ統一。休憩所を南の平地へ移し、橋南端から通常歩行で起動するテストを追加した。

実入力テストでは、テスト操縦が橋の側面段差にJUMPを使わず停止した。デジタル入力の物理再現で特定し、近くの段差へジャンプする操縦に修正。ゲームの物理を無効化せず、修正後は死亡0で3紋章・門開放・ゴールまで通過。6体型各2回、代替ミッション順も通過した。

再批評：更新画像6枚とコード・衝突検証を確認し、今回の改善ゲートとして限定付き合格。次の制作へ進むことを承認。非阻害の残件は道が斜面へ部分的に埋まる見た目。共通の道に幅方向9分割を加えて改善した。

画面：[開始](screenshots/expedition/stage-2-start.png)、[横画面](screenshots/expedition/stage-2-844.png)、[ボス警告](screenshots/expedition/stage-2-boss-warning.png)、[門開放](screenshots/expedition/stage-2-gate-open.png)。

### ステージ3：青の水庭と潮騒の神殿 — 合格

初回指摘：水門起動後の見た目に残水があり物理の水解除と不一致。輪の順序を誤ったときにACTIONと誤案内。北斜面から屋根・大水道の上部梁へ通常の移動とジャンプで入り込める。

修正：排水面は庭底の最低地形より下まで下げ、蓮も追従。輪は「通過」と案内。屋根と梁に表示どおりの衝突、屋根上の宝石に描画と同じ12頂点の凸包衝突を追加。屋根下面で止まり外へ戻れること、梁に身体が入らないことを通常入力の物理回帰で確認した。

再評価：排水前後を水庭への実移動で近接撮影。水門を後回しにする順でも死亡0で3紋章・開門・クリア。批評エージェントが画像と11テストの独立実行、屋根からの帰還を確認し、必須指摘なしで限定付き合格。合格後にステージ4へ進んだ。

画面：[開始](screenshots/expedition/stage-3-start.png)、[排水前](screenshots/expedition/stage-3-water-before.png)、[排水後](screenshots/expedition/stage-3-water-after.png)。

### ステージ4：夕映えの街と忘れられた時計塔 — 合格

指摘：縦画面の地図を折りたたむと残り時間が見えない。副題では止まった時計を動かすが最初から時計針が回る。実入力の斜め経路では西の屋台に当たる。

修正：巡回中は選択ミッションや通知と独立して残り秒・次の輪を常時案内。番人討伐時から時計針が回る演出に変更。屋台を通りの脇へ移動した。

再評価：実入力の通しプレイと、390px縦画面・地図を閉じた状態の実移動を追加検証。死亡0でクリア。時間切れ・再始動・通知が消えた後の秒表示も確認。更新7枚を確認した批評エージェントが必須指摘なしの合格。合格後にステージ5へ進んだ。建物の形・戦闘パターンには今後の磨き込み余地がある。

画面：[開始](screenshots/expedition/stage-4-start.png)、[縦画面の巡回タイマー](screenshots/expedition/stage-4-timer-portrait.png)、[開門](screenshots/expedition/stage-4-gate-open.png)。

### ステージ5：星座の庭と天空の巨人 — 合格

指摘：西外周の高い地形からジャンプすると、小観測塔の円錐屋根に身体が約0.18m入り込む。塔の本体には衝突があるが屋根にはなかった。

修正：描画と同じ8角の円錐凸包を屋根に追加。通常の移動と高跳躍で屋根に接触して止まることを物理回帰で確認した。

再評価：批評エージェントが独立して同じ高跳躍を再現し、接触・貫通防止・死亡0を確認。星座と守衛による盾解除、二連続衝撃波と攻撃できる隙、実入力の3紋章・開門・ゴール、PC/縦/横画面の案内を確認して合格。修正必須の指摘は解消した。地形や道の構成には他ステージとの共通性があり、夜空の演出にも改善余地が残る。

画面：[開始](screenshots/expedition/stage-5-start.png)、[ボス警告](screenshots/expedition/stage-5-boss-warning.png)、[門開放](screenshots/expedition/stage-5-gate-open.png)。

通し物理検証からの追加修正：ステージ4/5の崩壊橋のかけらを、地形ではなく橋の上面に合わせた。重量型で歩行・ジャンプして回収できることを確認。

## 4.1 — 景観の再批評（2026-10-04）

ユーザーからステージ品質への再指摘を受け、同じ独立批評エージェントで評価を再開。前回の合格を景観品質の合格として扱わないことを確認した。

第1回指摘：単一の水平な箱と矩形段差、十字の直線道路と円形広場が配置確認用の画面に見える。開始画面の空いた床が大きく、近景の樹冠が主要ランドマークを隠す。

対応：三角形地形、曲線の道、東の遺跡台地、西の展望丘、浅い川と実衝突の橋、大樹の幹・枝・根、固有の果樹園と壊れた遺跡を実装。展望台・洞窟・石積みに探索用かけらを配置。

第2回画像評価：『平面の配置図から、丘・橋・遺跡・大樹を見渡せる谷になった』。各地域の輪郭と展望台への導線は改善。残件は画面下の地形端、短い横画面のキャラの小ささ、門を隠す大樹の幹。

対応：カメラ手前へ景観の地面を延長。短い横画面のカメラを寄せる。大樹の幹を連続したテーパー形状にして西へ移動し、門の視線を開く。中・高画質の太陽の影を追加。

最終再評価：主要3点の改善を確認し、横画面の目的表示がキャラに重なる箇所を除き、静止画で見える重大なプレイ妨害はないと評価。そのHUDも修正して再撮影した。太い単色の道・規則的な遠景の山には簡素さが残る。今回の改善は合格だが、商用作品相当の完成度、移動中の遮蔽、実機性能を保証する評価ではない。画面は screenshots/valley/ に保存。

## 2.1 ステージ批評と改善記録

2026-10-03。独立した批評エージェントによるコード・5ステージの画面評価を受け、修正して再評価するループを実施した。人間の初見プレイテストではない。

## 第1回：仕掛けが読めない

指摘：風と水の有効範囲が見た目と一致しない。崩壊が予測しづらい。復帰直後に番人と接触する可能性がある。

修正：環境判定に横幅と高さを追加。風を強風・凪・予兆の周期にし、矢印の色と残り時間で知らせる。崩壊床にひびと赤くなる表現、残り秒数を追加。チェックポイント中央を番人の移動範囲から外した。再批評で見つかった「収集通知が崩壊警告を隠す」問題も修正。

## 第2回：経路の選択に意味がない

指摘：寄り道が行き止まり中心で、どのステージも直進とジャンプになりがち。

修正：4ステージに前方で合流する別ルートを追加。風車では短い風の橋と長い無風道、水庭では広い水路と狭い水上の道を選べる。大樹と天空城には星を集める細道を追加。崩壊都市は1枚→2枚→3枚の連続崩壊床と休息地点で構成。かけらはHPを8回復し、収集数に応じた最大3つの星をクリア時に保存する。

物理シミュレーションで軽量型・重量型の両方が全4分岐から前方へ合流し、無風道で風、水上道で水の影響を受けないことを検証。水庭の選択区間では、テスト操縦で軽量型は水路5.58秒／細道6.37秒、重量型は水路8.90秒／細道8.53秒。人間の最速記録ではない。

## 第3回：案内がプレイを遮る

指摘：中央の案内板が着地点を隠す。新旧の足場の重複で細道の幅が不明瞭。

修正：案内板を小さくして脇へ移し、全文は近づいたときにHUD表示。重複した旧足場を削除。別ルートの縁を金色にし、大きな装飾を置かない。

最終画面は `screenshots/critique/stage-1-final.png` から `stage-5-final.png` に保存。

## 通し検証からの追加修正

向かい風の制限がキャラクターの全速を基準にしていたため、斜め入力や加速中には押し戻される問題を回帰テストで再現。実際の前進速度を基準に修正した。弱いスティック入力でも急に後退へ切り替わらず、入力を離すと流される。橋の風の範囲には着地・踏切用の余白を確保した。

ブラウザの自動操縦はキー入力の通信遅延を考慮し、端から1.25mでジャンプを始め、キー状態が変わったときだけ入力を送る。失敗直前の移動履歴を記録する。瞬間移動、物理状態の書換え、仕掛けの無効化は使用しない。

## 最終批評と限界

批評エージェントは今回の改善範囲を合格と評価。面白さは3/5で、経路選択と判断は増えたが、最高品質という評価ではない。柱が一部案内板に重なる場合がある。人間の初見プレイ、iPhone/Android実機の操作感、全体型での最適経路は未検証。

# 通し検証の操縦修正

2026-10-05。[ブラウザの失敗](browser-failure.md)は、冒険5ステージ完走後のタイムアタック1で死亡1回、果樹園の敵2体を倒し、1体が残った記録。途中の成功を全体成功とは扱わない。

純Nodeで同じLV5人型・実Course・cameraFollow・視点の逆変換・デジタルキーの量子化を使い、入力更新間隔と初期カメラ位置を変えた。旧操縦は敵の中心まで入り、近距離で停止したときに向きが逆になって攻撃を外し続け、HP死亡した。落下は発生していない。ただしブラウザの敵残数まで完全に同じ再現ではなく、同じ操縦の問題を確認した比較実験である。

- [変更前の観測](before.json): LV5とLV1それぞれ、更新間隔2/3/4/5/6/8/10物理tick×初期位置2種類の14条件。LV5では8/10tickの4条件でHP死亡。LV1の追加比較は5条件でHP死亡した。
- [敵の1.8m手前で止まる比較](after.json): LV5、更新間隔2〜10tick×初期位置2種類の18条件すべて果樹園報酬取得・死亡0。変更前のLV5の14条件に7/9tickの4条件を追加した比較である。ACTION周期と視点処理は維持。報酬・ルーン・ボスの移動目標も維持。

ゲームの命中条件や敵の強さは変更していない。通常の移動・ジャンプ・ACTIONによる操縦を修正し、最終の実ブラウザ確認は[QA](../../../QA.md)に記録する。純Nodeの成功を実ブラウザ完走の代わりにはしない。

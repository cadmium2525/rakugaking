# 6.0 の検証画像

2026-10-04〜05。実キー・マウス・CDPタッチで操作した開発版の画像と観測記録。
位置・HP・ミッション状態の書き換えや、撮影用の瞬間移動は使用していない。
保存データの既クリア履歴を用いた検証は、初期難度の証明として扱わない。
JSON内の撮影ファイル名は元の`qa/v6/`パスを保持している。同名の画像をこのフォルダまたは対応する比較フォルダから参照できる。

- `before/`: 第2改善で指摘された近接遮蔽と景観の記録。
- `action-*-frame-*.jpg`: CDPによる実描画の連続フレーム。PNG単体から動きを推定しない。
- `field-*.png`: 地域を歩いて到達した景観。撮影担当と独立批評担当の記録を区別する。
- `independent-before/`: 第2改善（76点）の批評担当による独立操作と観測記録。
- `independent-after/`: 近接遮蔽と景観の追加修正後の独立操作と観測記録。
- `camera-before/`: 壁への侵入修正後に見つかった、自キャラの見切れの再現画像とレンズ位置。
- `camera-overhead/`: 上方への退避だけでは頭の面が画面を占めた再現画像。
- `camera-side/`: 横方向への退避修正後、家の周囲を歩いた92観測と縦横画面。HUD比較の操縦側の対象取り違えと訂正も記録。
- `camera-market/`: 市場のひさし下を歩いた35観測と修正後の縦横画面。

採点と限界は [全体批評](../../WHOLE_GAME_CRITIQUE.md)、機能回帰と配信確認は [QA](../../QA.md) を参照。
スマートフォンの実機性能、初見プレイヤーの感想は検証していない。

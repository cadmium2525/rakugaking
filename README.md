# ラクガキアドベンチャー

1枚の紙に自由な生き物を描き、立体になったキャラクターで5つのコースを攻略する、スマートフォン向けブラウザゲームです。描画・立体化・物理・保存はブラウザ内で動作し、画像生成APIは使用しません。

2.0では、描画中に全身の3D完成形を常時表示します。正面・斜め・横から接続や大きさを確認できます。コースも大樹・風車・水庭・崩壊都市・天空城へ拡張し、途中復帰、寄り道のかけら、動く番人を追加しました。青い輪が復帰地点です。旧コースのタイムは新記録と比較せず保存内に退避し、キャラクターと進行は引き継ぎます。

**公開URL:** https://cadmium2525.github.io/rakugaking/

7.0では、各ステージの主な遊びと入口・出口・課題の配置を作り直しました。風車の谷は配達鳥の同行、水庭は排水後に現れる真珠探し、街は灯火巡回と歯車を使った時計修理、天空城は時間差で来る守衛から月の灯を守って巨人へ挑む構成です。街には必須の敵・ボス戦がありません。[各ステージの特色](docs/STAGE_IDENTITIES.md) / [独立批評と改善](docs/STAGE_IDENTITY_CRITIQUE.md)。

6.0ではゲーム全体の批評を受け、ACTIONを予備動作・命中・回復のある3段連撃と空中スピンに変更しました。向き、踏込、敵の怯みと吹き飛び、防御・撃破の動作、効果音を追加。自キャラを隠す近接の相手だけを薄く表示します。ステージ2〜5を144×136m以上の歩けるフィールドへ広げ、道外の探索と4個の寄り道報酬、噴水公園、城裏への尾根を追加しました。風の扇、水の広がる波、時計の十字と、異なるボス攻撃に挑戦できます。[全体の批評と改善](docs/WHOLE_GAME_CRITIQUE.md)。

5.0ではステージ2〜5も広い地続きのミッションフィールドへ変更。風車の復旧、水門と蓮庭、時間制限の灯火巡回、星座と二連続衝撃波の巨人に挑戦できます。各ステージは制作後に独立した批評エージェントで確認し、指摘を修正して合格してから次へ進みました。[ステージの内容](docs/EXPEDITION_STAGES.md) / [批評と修正](docs/STAGE_CRITIQUE.md)。

4.1ではバケツの塗りつぶしを追加。囲んだ範囲をタップして色を入れ、輪郭は線のまま残せます。ステージ1を起伏のある谷へ作り直し、川と橋、坂で登る遺跡、展望台と洞窟の寄り道、大樹の景観を追加しました。

4.0では落書き画面を刷新。全身を1枚の紙に描き、開いた線をそのまま立体化できます。自由な色、線・面の移動や複製、犬・ドラゴンの下絵に対応。[新しい描き方](docs/SKETCH_EDITOR.md)を参照してください。

3.0ではステージ1を広い地続きのフィールドへ変更。果樹園の敵討伐・遺跡の仕掛け・ボス戦を好きな順で攻略し、3つの紋章を拾うとゴールの門が開きます。地図と目的地案内を追加しました。[新ステージ1の内容](docs/FIELD_STAGE.md)を参照してください。

2.1では批評と修正を3回繰り返し、前方で合流する分岐、風の凪と予兆、崩壊床のひびとカウントダウンを追加。収集物はHPを回復し、クリア時の星として保存されます。[批評・改善記録](docs/STAGE_CRITIQUE.md)に評価と残る課題を記載しています。

GitHub Pagesで起動・3D生成を確認済み。オンラインランキングは未設定、iPhone/Android実機は未検証です。

## 起動

Node.js 24.12以上を使用します。

```sh
npm ci
npm run dev
```

表示されたlocalhost URLを開きます。ビルド確認は `npm run build`、`npm run preview`。HTMLをファイルとして直接開かず、HTTPで配信してください。スマホでLAN内から確認するときは `npm run dev -- --host 0.0.0.0` を使い、端末からPCのLANアドレスへ接続します。

## 遊び方

- 「ラクガキする」で全身を1枚の紙に描く。「ペン」は開いた線、「塗りつぶし」は囲んだ範囲へのタップ、「面」は塗りつぶした形の描画。下絵、自由色、部分消しゴム、選択・移動、拡縮・反転・複製と3Dプレビューを使えます。「誕生させる」で保存して操作できます。
- PC: WASD/矢印で移動、Spaceでジャンプ、EでACTION。スマホ: 左スティック、右のジャンプとACTION。横向き推奨。
- ACTIONをリズムよく押すと3段連撃。押しっぱなしでは連撃しません。ジャンプ中は全周の空中スピンになります。広場の木の練習相手でも試せます。
- フィールドの画面をドラッグして見回せます。PCはQ/Rでも回転、Cまたは「北へ」で視点を戻せます。移動と目的地の矢印は視点に合わせて変わります。
- 冒険: 大樹の谷→風車と灯台→水庭と神殿→街と時計塔→星座と天空城。各フィールドで3つのミッション報酬の紋章を拾うと出口の門が開きます。地図で目的を選び、ゴールすると次のステージへ。配達鳥は近くでACTIONして9m以内で案内。水庭の真珠は排水後に出現し、真珠と街の歯車は順不同で拾えます。街の時計は灯火と歯車を終えてからACTIONで修理。ステージ5は灯台の耐久を守って2方向から来る守衛を3波迎撃すると、星座と合わせて巨人の盾が消えます。
- レベルは1〜20。初回クリアと再走でEXPを獲得。新しい落書きは大きさ・描いた量・厚みが能力を決めます。色は自由に選べます。旧形式のキャラクターは従来の能力計算を維持します。
- タイムアタック: 5ステージを同じキャラクター・開始時能力で通走。ロード時間を除き、ポーズと失敗の時間を含みます。タブが隠れた走行はランキング対象外。
- 一時停止からリトライ、ホーム、画質変更ができます。

## ホーム画面に追加・オフライン

[公開ゲーム](https://cadmium2525.github.io/rakugaking/)を開き、iPhoneはSafariの共有メニューから「ホーム画面に追加」、AndroidはChromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。表示名はブラウザによって異なります。PCの対応ブラウザでもインストールできます。

初回は通信が必要です。ゲームと必要ファイルの保存が終わると、ホーム画面からオフラインでも起動・作成・プレイできます。ランキングには通信が必要です。OSによるサイトデータ削除・容量不足時はオフライン利用できない場合があります。

更新はバックグラウンドで取得します。新しいゲームの通知が出たら、落書き画面を保存して閉じ、広場へ戻って「保存して更新」を押せます。ほかのゲームのタブが開いている場合や保存に失敗した場合は更新を待ちます。ゲームの全タブ・アプリ画面を閉じて再度開く方法も使えます。旧版に通知ボタンがない場合はこちらを使ってください。PC画面右下に現在の版を表示します。キャラクターや進行の保存を更新処理で消すことはありません。

manifest・Service Worker・192/512pxアイコン・Androidのmaskable・iPhone用180pxアイコンを同梱。[PWAの仕様](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)に沿った構成です。実機のホーム画面追加は未検証です。

## 保存とランキングの仕様

IndexedDBを優先し、使用不能ならlocalStorageへ保存します。キャラクター最大24体、進行、EXP、直近20件の有効な記録、ベストを保持します。走行途中の復元はしません。保存不能時は画面に通知します。ブラウザのサイトデータ削除で保存が失われます。

ランキングは独立した無料枠対応のWorkers＋D1バックエンドです。未設定・通信失敗でもゲームは遊べます。名前・タイム・レベル・キャラクター情報が公開対象です。匿名トークンで自分のベストを更新し、TOP100と自分の順位を表示します。[設定と検証仕様](backend/README.md)を参照してください。クライアントゲームのため巧妙な不正タイムの完全な検知はできません。

## GitHub Pages公開

1. 公開先リポジトリへこのプロジェクトをpushします。無料Pagesを使う場合は公開リポジトリを使用します。
2. Settings → Pages → Sourceを **GitHub Actions** に設定します。
3. main/masterへのpush、またはActionsの「Verify and deploy Pages」を手動実行します。
4. lint・単体テスト・ビルド・配信ビルド起動テストが成功後、distを公開します。
5. 発行URLで実機操作とランキングの本番接続を確認します。

Viteの相対baseによりリポジトリのサブパスへ配信できます。秘密鍵は不要です。ランキングendpointは `public/ranking-config.json` に公開HTTPS URLを設定して再ビルドします。GitHub操作は[公式Pages手順](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)に準拠。masterブランチからのActions公開を確認済みです。

## 検証・構成

```sh
npm run lint
npm test
npm run build
npm run test:e2e
node tests/production-smoke.js
```

ローカルのブラウザテストはMicrosoft Edgeを使用します。E2Eが開発サーバー5186とランキングAPI8787を起動します。CIの配信ビルドテストはChromiumを使用します。

- Three.js: 押し出し形状・階層アニメーション・WebGL描画。
- Rapier compat 0.19.3: 固定60Hzの衝突とキャラクター移動。バージョン固定理由はQAに記載。
- Vite: 開発・静的ビルド。Playwright、Node test、ESLint、Prettier: 開発用。
- `src/core`: 形状・能力・物理・保存・時計。`src/game`: コース・描画。`src/ui`: エディタ・操作。`backend`: 任意のランキング。

[検証結果と既知の制限](docs/QA.md) / [開発フェーズ記録](docs/DEVELOPMENT.md)
